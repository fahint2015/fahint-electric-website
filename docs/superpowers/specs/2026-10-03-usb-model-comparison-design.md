# USB 型号对比

日期：2026-10-03

## 已批准范围

用户已同意上一轮提出的方案：USB 产品卡片可加入 2–3 款型号进行对比，突出参数差异，每款保留详情和询价入口，手机端横向查看。沿用既定主代理内联实施、本地预览、不推送的工作方式。

## 交互与外观

- 仅 USB 系列列表增加原生勾选框；其他系列和相关产品卡片不增加对比功能。
- 列表上方设置浅灰、圆角的对比工具条。说明可选 2–3 款，显示选择数量和可移除的型号；未够两款时禁用对比。已选三款时禁用其他型号的勾选，仍可取消已选型号。
- 工具条在产品列表范围内吸顶，使用现有深蓝、蓝绿配色，不增加底部悬浮按钮，不遮挡既有联系按钮。
- 点击对比打开浏览器原生 dialog，保留 Escape、关闭按钮、焦点恢复及键盘访问。使用语义表格，首列为参数，后面按选择顺序展示产品图片、型号、详情和询价入口。
- 差异行使用浅色背景和文字标记，不单独依赖颜色；提供“仅显示差异”开关。相同规格时说明没有差异，可关闭开关查看全部。
- 手机产品列表仍为双列；对比表仅在面板内部横向滚动，保留行标签，关闭按钮始终可见。

## 数据与状态

- 现有 `catalogProducts.js`、`usbFilters.js`、`usbDimensions.js` 为唯一事实来源，不复制 37 款参数、不新建数据库。
- URL 的 `compare` 参数存放最多三个已发布 USB SKU；忽略未知型号、其他系列、重复值。切换/清除筛选不清除对比；清空对比不清除筛选。刷新、详情页返回可恢复选择，不在本地持久存储客户信息。
- 对比行：接口、AC 插座额定参数、充电类型、USB 合计输出、USB-C PD 单口上限、接线方式、设备宽度、总高度和深度。统一纯格式差异，不补造参数。
- F4P 明确为无 AC 插座的 USB 充电器。普通 USB 的合计输出与 PD 单口最大值分行；PD 合计输出显示需要确认分配，不能相加端口上限。
- 尺寸仅取与原始图纸匹配的尺寸来源；未公开值显示“Not published — please confirm”，4200 系列不得借用其他型号尺寸和接线方式。PD 20/36W 图纸只有机身高度，不冒充总高度。
- 每款询价复用已验证的 `resolveInquiryContext` / `inquiryContactHref`，不预选颜色；Contact 保持七系列选择。
- 不新增路由或依赖，不改 canonical、域名、邮件发送方式。本轮不做多型号询价清单。

## 验收

1. 只能选择 2–3 款进行对比；移除和清空正常，不影响筛选。
2. URL 验证与恢复正确，不显示任意外部参数；跨系列不出现工具。
3. 常规、PD、F4P、4200 资料不完整的边界均准确；差异筛选和询价型号正确。
4. 关闭、Escape、焦点恢复、手机表格滚动可用；320/390/768/1024/1440 宽度不造成页面横向溢出。
5. 按 TDD 增补测试，运行全套测试与构建，浏览器实际核对后保存本地提交。

## 内联自查

范围只覆盖已批准的 USB 对比；没有邮件服务、全站重设计或新状态框架。显示字段均有已检查的源数据；缺项明确，不继承猜测。表格面板优于新页面（无需增加路由与部署入口），也不将长表直接插入原有产品列表。
