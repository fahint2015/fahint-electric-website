# 资料中心：第二批的第一个交付

日期：2026-10-02

## 目标与边界

承接用户已同意的“先资料中心，再选型工具”顺序，为采购商提供独立的 Resources 页面，集中已有原文件，并从产品内页进入对应系列资料。

本次只交付资料中心，不同时实现 USB 筛选、型号对比、多型号询价或正文预渲染。沿用现有深蓝、蓝绿、浅灰、圆角和英文内容，不重新设计全站。

沿用已批准的限制：主代理在当前分支内实施，不创建子代理；不接入邮件直达、统计或文件上传服务；不修改域名配置；先提供本地预览，不自动推送、合并或部署。

## 已核对的资料

仓库 `public/assets/documents/` 内有七个可用原文件：

| 资料 | 路径 | 用途 |
| --- | --- | --- |
| FAHINT 产品目录 | `assets/documents/fahint-product-catalog.pdf` | 全系列产品参考，约 13.3 MiB |
| GFCI 证书 | `assets/documents/certificates/ul-gfci.pdf` | GFCI 系列资料，须核对原始附页及具体型号 |
| 标准插座证书 | `assets/documents/certificates/ul-receptacle.pdf` | 标准插座系列资料 |
| USB 插座证书 | `assets/documents/certificates/ul-usb.pdf` | USB 插座系列资料 |
| 墙面板证书 | `assets/documents/certificates/ul-wallplate.pdf` | 墙面板系列资料 |
| 墙壁开关证书 | `assets/documents/certificates/ul-switch.pdf` | 原文件列出的墙壁开关，不适用于所有开关 |
| ISO 9001 证书 | `assets/documents/certificates/iso-9001.pdf` | 公司质量管理体系，不是产品认证 |

证书名称、路径、日期和说明已有 `src/data/certificates.js`；目录路径已有 `src/data/documents.js`。不再维护第二套相同文案或复制 PDF。

目前没有独立安装手册 PDF。已有产品页包含部分型号的尺寸图、安装参考及来源资料；这些仍标为在线参考，不冒充可下载安装手册。不为没有材料的型号生成证书、安装指南或正式数据表。

## 方案选择

1. **独立 Resources 页面（推荐）**：统一入口、可直接分享系列链接，并保留产品页的型号上下文。此次采用此方向。
2. 扩充 About 证书区：改动少，但采购商仍需到公司介绍页查产品资料，不利于日后增加真实文件。
3. 完整下载门户：型号级全文检索、批量打包和账号系统对当前七份文件没有必要，本次不做。

用户已同意推进资料中心；以下细节作为实施前的书面设计供确认。

## 页面组织

- 新页面路径为 `/resources`。桌面导航、手机菜单和页脚增加 Resources 入口；维持现有导航风格与断点。
- 页首用简洁标题与说明，随后是一张突出完整产品目录的横向卡片，提供查看和下载 PDF。手机上下排列，不做大幅装饰海报。
- 产品系列筛选来自现有七系列数据，提供 All product families 选项。采用原生选择控件和紧凑列表，避免在手机上排成长串标签。
- 证书列表使用统一圆角、缩略图、文件名称、文件编号、文件类型以及查看/下载操作。范围与签发日期可展开查阅，不在卡片上堆满细字。
- 公司 ISO 资料单独标明 Quality management，不能作为某个产品的认证依据。
- 没有独立系列证书的 Dimmers、Smart Switches 仍可查目录与产品页，并明确提示联系团队确认型号资料，不显示假文件或无效按钮。
- 文案说明：这些是已提供的原始参考文件，不是实时认证状态查询；购买前需确认具体型号、配置与当前覆盖范围。
- 保留 About 的现有证书区和旧锚点，增加到资料中心的入口，不破坏既有分享链接。

## 产品关联与资料准确性

- 两类产品内页的现有资料区都增加同一种资料中心入口，不再新增独立的大板块。
- 链接携带有效系列及已发布型号标识，例如 `/resources?family=usb-outlets&model=FTR15C-3100`。
- 资料中心验证这些标识后，显示来源型号及返回其规格/产品页的链接，并把技术资料索取入口指向现有 Contact 技术询价，沿用型号传递逻辑。
- 型号只用于定位和索取资料；按系列显示证书不等于确认该型号通过认证。不能根据共有文件号或型号前缀推断覆盖范围。
- GL20、工业 GFCI、组合开关等已有的型号审核提示不被这次改动覆盖或提升为已认证；证书描述与型号数据有冲突时先核对原文件，未经核实不扩展声明。
- 主动切换系列时清除不属于新系列的来源型号，未知系列/型号及草稿型号不回显；不将任意查询文本作为文件地址。
- 不新增个人信息持久存储，不改变前一批已经实现的询价配置连续性。

## 实现边界

- 路由沿用 `src/main.jsx` 的按需加载模式，新增一个资料页和局部样式。
- 文件路径、证书元数据、产品系列和型号均复用现有数据。只增加必要的系列与资料映射，不引入通用内容管理系统。
- PDF 查看使用普通链接，下载使用浏览器原生下载行为；不内嵌七个 PDF 阅读器，也不引入依赖。
- 本地文件链接全部通过 `publicAsset`，兼容 GitHub Pages 仓库子路径。
- 新页面使用现有 SEO 元数据系统，新增独立标题、简介、面包屑与发布路由；保持当前域名设置和 canonical 策略不变。不承诺本轮实现搜索排名或 AI 引用效果。

## 验收

1. 七份真实 PDF 均可打开/下载，没有重复拷贝、伪造文件或失效下载入口。
2. 七系列筛选、深链接、空系列资料提示、返回产品和技术资料询价可用。
3. GFCI 与 USB 产品页均可进入对应资料；无效、草稿或跨系列型号不会误带资料上下文。
4. 公司 ISO 与产品系列文件明确区分，不把系列文件当作任意型号的认证保证。
5. 桌面和 320/390px 手机宽度无横向页面溢出；控件和下载链接可用键盘操作，有清晰焦点和名称。
6. 新页面元数据、发布路径与仓库子路径文件地址通过检查；邮件服务和域名配置没有变动。
7. 复用现有 Vitest/Testing Library，先写相关失败用例再实现，完成后运行针对性回归、完整测试、构建和真实浏览器检查。

- 保留既有配色、组件及旧资料入口，不引入新服务或依赖。
