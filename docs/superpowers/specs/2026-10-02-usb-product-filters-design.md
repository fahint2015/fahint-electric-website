# USB 列表筛选：已确认方案

日期：2026-10-02

## 用户确认与范围

用户已确认在 Products → USB Outlets 的现有 Search models / Configuration 区域增强筛选，并要求开始实施。这里记录已确认的方案，不另建工具页面，也不扩展到型号对比或多型号询价。

继续在 `codex/prelaunch-buyer-tools` 当前目录内由主代理实施；本批只提供本地预览。不推送、合并或部署，不改变邮件、域名、认证声明或产品参数。

## 页面与交互

- 保留顶部海报、产品网格、购买指南和其他系列页面。
- 型号搜索旁提供 USB ports、Receptacle rating、Charging output 三个原生选择框。Charging output 取代 USB 页原来含义较笼统的 Configuration，不再堆叠重复的功率筛选。
- USB ports：双 USB-A、USB-A + USB-C、双 USB-C、四 USB-A。
- Receptacle rating：15A、20A、USB only。F4P 是独立 USB 充电器，不归入 15A 或 20A 交流插座。
- Charging output：5V 3.1A / 3.6A / 4.2A / 5A，及 USB-C PD 20W / 36W / 65W。5V 值是合计输出，PD 值是已公布的 USB-C 单口最大值，不能当作双口同时输出或累加为 130W。
- 各条件与型号搜索取交集；显示结果数量，保留 Clear filters 和选型帮助。零结果时保留条件并提示清除，不自动改变客户选择。
- 用 URL 查询参数保存 USB 的搜索和筛选，刷新、分享及查看产品后返回可恢复条件；输入和选择过程中不跳回页首，不增加每次按键的历史记录。
- 无效筛选参数按 All 处理，不回显为选项；不把查询参数作为链接或 HTML。
- 桌面紧凑四列，较窄屏幕两列；手机搜索及接口占整行，额定电流与充电规格并排。产品继续双列，沿用网站圆角与颜色，保留键盘焦点和足够点击区域。

## 数据与实现

已有 37 个已发布 USB 型号。复用 `getCatalogProducts`、`filterCatalogProducts` 和各型号的 `specificationSummary` / `group`，不新建重复的型号数据库。

一个小型 `src/data/usbFilters.js` 负责筛选词汇及规格归一：统一 Dual USB-A 与 2 × USB-A 等现有写法；区分交流插座额定值、普通 USB 合计电流及 PD 功率。缺少某项数据时不猜测参数。

`LineDetail.jsx` 只对 USB 启用这些控件和 URL 状态，其他系列维持现有搜索、Configuration 和排列。查询更新复用 `RouteFocusManager` 已支持的 `preserveScroll` 约定。过滤后的页面仍以系列主路径作为搜索元数据标识。

采用现有列表增强方案；独立向导会增加步骤，独立选型页面会分散现有产品入口，本批均不采用。无新依赖、全局状态库或服务。
